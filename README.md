# ShopTalk
ShopTalk facilitates online shopping by turning complex queries into intuitive conversations. The challenge here is to create an AI assistant that understands detailed requests, such as finding a red men's shirt and providing precise product suggestions. Focus on enhancing user interaction with real-time, natural language responses, ensuring a seamless and engaging shopping experience. Embrace ShopTalk, where shopping becomes as simple as a chat.

## Setup
### 1. Environment Configuration
Pre-requisite: [conda](https://conda.io/projects/conda/en/latest/user-guide/install/index.html)

Assuming that you are currently in your extracted ShopTalk directory, i.e. the root of this project:
```
cd ..
conda create --name imagebind python=3.10 -y
conda activate imagebind
git clone https://github.com/facebookresearch/ImageBind
cd ImageBind
pip install .

cd ../ShopTalk
pip install .
```

The two pip install commands should result in nearly every dependency needed to run our project being installed (including our most troublesome dependency, ImageBind).

**All following commands should be run from the project root, e.g. `.../ShopTalk/`** 

### 2. Confirm Required File Presence
All of the following files should have already been included in your distribution of this project:
* `faiss_index.bin` - the product-oriented Vector DB (created by FAISS) [this file is created by `generate_vector_db.py`]
* `index_to_product_id.pkl` - mapping of VectorDB indices -> Amazon Product IDs [this file is created by `generate_vector_db.py`]
* `product_blurbs/combined_blurb_dict.json` - mapping of Amazon Product IDs to various metadata (including Amazon Image IDs) [this file is generated by `EDA/DescriptionGenerator.py`]
* `images.csv` - mapping of Amazon Image IDs -> server image paths. 
* `server/static/images/[VARIOUS]` - subdirectories from 00-FF, containing all product images.
* `server/server.py` - Flask server script, used to run the server
* `bpe/bpe_simple_vocab_16e6.txt.gz` - A dependency of ImageBind that they didn't bundle correctly. Its presence here side-steps the issue.

### 3. Install Additional Requirement
If you would like to run ShopTalk on GPU, run `pip install faiss-gpu`.
If you would instead like to run ShopTalk on CPU, run `pip install faiss-cpu`.

### 4. API Keys

Make a file named ".env" in the project root. Fill it with:

`OPENAI_API_KEY="your_openai_api_key"`

### 5. Download Images

Download the ~3 GB file [`abo-images-small.tar`](https://amazon-berkeley-objects.s3.amazonaws.com/abo-images-small.tar) from the Amazon Berkeley Objects homepage. Extract it and move all the contents of its `images/small/` directory into the project's `server/static/images` directory. If you've done this correctly, the project will have directories like `server/static/images/00`, each full of many small images. Then move images.csv.gz from /metadata to main ShopTalk dir and unzip.

### 6. Running the Vector DB generation Code
This step, a pre-requisite to running the server.

Run `python generate_vector_db.py`. Various flags are available, though the defaults are suitable for typical use. This script has an updating progress bar that shows process of embedding ~25k total products. It may take 1-2 hours to complete on a highly capable machine.
